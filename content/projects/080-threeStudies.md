El repositorio con las primeras versiones se encuentra en: [THREE.studies](https://github.com/EmilioOcelotl/THREE.studies).

Para esta versión, despliego la instancia de un [servidor OSC web personalizado](https://github.com/EmilioOcelotl/osc-web-server) y la biblioteca [treslib](https://github.com/EmilioOcelotl/treslib), ambas desarrolladas por mí. También implementa una [variación](https://github.com/EmilioOcelotl/MMLL) de la biblioteca MMLL.js, trabajada en conjunto con Marianne Teixido, basada en el [proyecto original](https://github.com/sicklincoln/MMLL) de Nick Collins.

Audiovisual studies for the browser. This project was developed in collaboration with Iracema de Andrade.

The repository with the initial versions is available at: [THREE.studies](https://github.com/EmilioOcelotl/THREE.studies).

The latest version is archived at: [THREE.studies-II](https://github.com/EmilioOcelotl/THREE.studies-II). For this version, I deployed a [custom web OSC server](https://github.com/EmilioOcelotl/osc-web-server) and the [treslib](https://github.com/EmilioOcelotl/treslib) library, both developed by me. It also includes a [variation](https://github.com/EmilioOcelotl/MMLL) of the MMLL.js library, created in collaboration with Marianne Teixido, based on the [original project](https://github.com/sicklincoln/MMLL) by Nick Collins.
